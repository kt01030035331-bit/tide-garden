# 潮汐群岛

一个可拖动锚点的程序化像素海岛原型。

## 运行

将 `tide-garden.html` 下载到本地，用 Edge、Chrome 等现代浏览器打开。页面无需安装依赖或启动服务器，可离线运行。

## 操作

- 拖动编号锚点，让岛屿靠近或分开。
- 用「添加锚点」「删除选中」调整岛屿布局。「重置」恢复初始位置。
- 用「地形场」查看锚点影响叠加后的数值分布。
- 锚点聚焦后可用方向键移动。按住 Shift 增大步长，按 Delete 删除。

## 实现

Canvas 2D 在低分辨率画布上绘制地图，再以像素化方式放大。锚点对周围像素的影响相加，并叠加固定坐标噪声。锚点移动时，当前地形场逐帧接近最新目标，近岸先经过浅水和沙滩，再到草地。树木、岩石等精灵固定在地图坐标上，随当地地形变化淡入或淡出。开启系统减少动态效果后，地形和道具即时更新。

## 素材

大灌木、大岩石和碎石来自 myobln 的 [Mini Meadow](https://myobln.itch.io/game-assets)，原素材为 CC0 1.0。项目裁掉了透明留白并按岛屿调色板重配色，将这三个精灵内嵌在 HTML 中。
